# Fontes locais

Os arquivos WOFF2 são servidos pelo mesmo domínio do aplicativo, sem conexões do navegador ao Google Fonts. Mantidas as famílias e pesos da interface: Anton 400; DM Sans 400–700; IBM Plex Mono 400/500/600/700; Inter 400–800; Manrope 600–800. Subconjuntos latin e latin-ext cobrem o português.

Origem dos binários: Google Fonts CSS API / fonts.gstatic.com, obtidos em 20/09/2026. As versões são identificadas nos próprios nomes internos dos arquivos. Licenças SIL Open Font License 1.1 originais preservadas neste diretório, obtidas no [repositório oficial Google Fonts](https://github.com/google/fonts/tree/main/ofl). Os arquivos não foram modificados.

Licenças: [Anton](anton-OFL.txt), [DM Sans](dmsans-OFL.txt), [IBM Plex Mono](ibmplexmono-OFL.txt), [Inter](inter-OFL.txt), [Manrope](manrope-OFL.txt).

Os HTMLs de referência fora do build React continuam sendo baselines históricos; o aplicativo usa `src/fonts.css`.
